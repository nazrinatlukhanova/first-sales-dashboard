 First Sales Dashboard (Power BI Exam Project)

This is my first Power BI dashboard created as an exam project for my Data Analytics course. 
 📊 Dashboard Overview
Here is a preview of the Sales Dashboard:

![Dashboard Preview](Screenshot.png)
Key Features & Metrics
- KPI Cards:Total Quantity, Total Cost, Total Sales, and Total Profit.
- Visualizations:
  - Sales by Category (Bar Chart)
  - Profit by Region (Horizontal Bar Chart)
  - Sales by Segment (Pie Chart)
  - Top Products (Ranked Bar Chart)
  - Monthly Sales Trend (Line Chart)
- Interactivity: Region, Customer Segment, and Product Category slicers for filtering.

Tools Used
- **Power BI Desktop** (Data Modeling, DAX, and Visualization)
